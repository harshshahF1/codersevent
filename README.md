# Department Inventory & Student Item Issue Management System

Premium Express + EJS + SQLite application. See setup instructions below.

## Setup
1. Install Node.js 18+ (Node 20 LTS recommended).
2. Clone the repository and run `npm install`.
3. Run `npm run seed`.
4. Run `npm start` and open http://localhost:3000.

Demo coordinator: `coordinator@dept.edu` / `Coord@123`.
Demo students: `2026DFIS001` through `2026DFIS008` / `Student@123`.

The demo database is created locally in `data/inventory.sqlite`. Do not use demo credentials in production. Change the session secret and credentials before deployment.
